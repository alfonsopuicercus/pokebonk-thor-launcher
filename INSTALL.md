# Install on your AYN Thor

1. Open [the GitHub release](https://github.com/alfonsopuicercus/pokebonk-thor-launcher/releases/tag/v0.1.0-preview) in Chrome on the Thor.
2. Under **Assets**, download **PokeBonk-Thor-Launcher-0.1.0.apk**. Open it from Downloads/Files and install it. If Android asks, allow that browser/file app to install this APK; you can turn the permission off afterward.
3. Open **Pokébonk for Thor**, then choose **Play in Chrome**. The launcher tries to open Chrome on the primary/top screen. If the Thor keeps it elsewhere, move Chrome using the Thor's app/screen selector.
4. Use normal Android gamepad mode and disable a touch-mapping overlay for Pokébonk. Tap the website once to enable sound, then press a face button with both sticks released. Keep Chrome focused while playing.
5. Use the game's **Enter** tab to sign into an existing username/password account, or **Create account** to make one yourself. Check the expected progress before playing a longer run.

**Google login:** the current official game does not expose a Google sign-in option. This APK keeps the website's own account options available; it cannot add Google login to that service.

## Already have a save?

Use the same browser and normal profile you used before. **Choose another browser** opens Android's browser chooser, useful if your existing account/session is in Firefox. Chrome and Firefox have separate cookies and guest sessions. Private/incognito mode also has separate storage. An existing PokéSurvivor account/save belongs to a different game and is not imported into Pokébonk.

The launcher stores no progress. Uninstalling this launcher does not clear browser site data. Avoid clearing Pokébonk's browser data if you rely on a guest session.

## Buttons

- Left stick moves; right stick controls the camera.
- Bottom/right/left/top face buttons: jump / dash / interact / Ultimate.
- LB toggles aim; RB locks a target. LT dashes; RT uses Ultimate.
- Start pauses; Select opens the map.
- Stick/D-pad navigates menus; bottom face confirms; right face goes back; LB/RB switches tabs.
- Remap under **Settings → Controls** if the physical labels differ. The launcher also has a **Controls & sign-in** guide.

For a full-screen shortcut, Chrome's menu may offer **Add to Home screen / Install app**. That is optional and is supplied by the website/browser. The APK itself opens a regular browser tab so account login remains in the browser.
